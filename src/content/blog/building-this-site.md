收藏内容很容易，形成自己的知识结构却很难。这个网站尝试让写作足够轻，同时让内容可以长期迁移。

文章全部使用 Markdown 保存，版本历史留在 Git 中，网页只是内容的一种呈现方式。即使未来更换框架，原始文字仍然属于我。

## 当前工作流

1. 在本地或网页编辑器中新建文章；
2. 添加标题、摘要、日期与标签；
3. 保存到 GitHub；
4. 静态站点自动重新构建。

工具应该降低表达的阻力，而不是变成新的维护负担。
